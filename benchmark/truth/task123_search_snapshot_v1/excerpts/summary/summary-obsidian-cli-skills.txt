
This document outlines the usage, command capabilities, and operational patterns for the official [[obsidian-cli]] introduced in Obsidian v1.12+. It covers execution modes including the interactive [[obsidian-cli-tui-mode|TUI mode]] and headless [[obsidian-cli-direct-mode|direct mode]] execution, detail workflows for [[obsidian-cli-vault-health|vault health analysis]], daily note capture, workspace layout management, and advanced features such as executing JavaScript via the [[obsidian-cli-eval|eval command]]. It also addresses environment integration for [[obsidian-cli-wsl-integration|WSL environments]] with GPU hardware acceleration.
