
Service workers are browser scripts that run in the background, capable of intercepting network requests and serving cached responses or client-side routing logic for a specific origin (e.g., `localhost:8080`). Service worker registrations persist in the browser client across server restarts and are not cleared by a standard browser hard refresh (Ctrl+Shift+R). When local web development servers switch builds or content on an existing origin, a stale service worker can hijack all fetch events, leading to unexpected 404s or client-side routing errors until manually unregistered via browser developer tools.
