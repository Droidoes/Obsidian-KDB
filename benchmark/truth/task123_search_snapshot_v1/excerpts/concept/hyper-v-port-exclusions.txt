
Hyper-V port exclusions are kernel-level port range reservations set by the Windows virtualization stack (appearing under PID 4, System, in Windows networking utilities). These reserved ranges block applications from binding to specific TCP ports. Crucially, tools inside WSL2 (such as `ss` or `lsof`) only enumerate Linux kernel sockets and are blind to these Windows-side reservations. Even in [[wsl2-mirrored-networking|mirrored networking mode]], Hyper-V port exclusions remain invisible inside WSL because they are placeholder kernel reservations rather than active open sockets. Verification requires host-level tools like `netsh interface ipv4 show excludedportrange protocol=tcp` or Windows `netstat`.
