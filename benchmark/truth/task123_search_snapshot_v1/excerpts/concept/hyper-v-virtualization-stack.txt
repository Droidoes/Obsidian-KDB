
The Hyper-V virtualization stack on Windows 11 underpins local VM execution for applications like Claude Desktop's Cowork workspace. System updates or service restarts can leave the Host Network Service (HNS) or Hyper-V Virtual Machine Management service (`vmms`/`vmcompute`) in a stuck or uncommunicative state. Remediation requires forcibly restarting `vmms` and `vmcompute`, resetting the HNS service via `net stop/start hns`, ensuring hypervisor auto-launch in `bcdedit`, and adding the active user to the `Hyper-V Administrators` local group to grant proper management permissions without full elevation.
